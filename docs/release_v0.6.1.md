## Overview

Yoghurt 0.6.1 is a maintenance release with dependency and CI updates. No intentional API or CLI behavior changes.

## Highlights

- Updated locked runtime dependencies: `httpx2` 2.12.0 → 2.13.1 and `tzdata` 2026.3 → 2026.5.
- Updated development tooling: `isort` 8.0.1 → 9.0.1, `black` 26.5.1 → 26.10.0, `pylint` 4.0.8 → 4.1.2, `pyright` 1.1.411 → 1.1.414, `ruff` 0.16.5 → 0.16.10, `tox` 4.61.2 → 4.64.9, `tox-uv` 1.36.0 → 1.36.1, and `coverage` 7.16.0 → 7.16.2.
- Updated `astral-sh/setup-uv` from 10.0.1 to 10.1.0 across CI and publishing workflows.
